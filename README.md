Assembly Processor Simulator

This project is a C# Windows Forms application developed to simulate the execution of assembly instructions using a microprogrammed processor architecture.

Features:

- Processor registers and memory
- Instruction register and program counter
- Source and destination buses
- ALU operations such as ADD, SUB, AND, OR and XOR
- Shift and rotate operations
- Flags and control signals
- Microprogram memory
- Instruction decoding and sequencing
- Binary object file loading

Purpose:

The project was developed as an academic exercise to better understand how assembly instructions are decoded and executed at the processor level and it's not fully functional.
